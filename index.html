HOW TO LOAD SCHEMATICS INTO YOUR WORLD

Never used a schematic before? Follow these straightforward steps to paste any downloaded build directly into Minecraft Java Edition.

Option 1

WorldEdit (.schem)

Best for Spigot, Paper, Fabric servers, or single-player with WorldEdit mod installed.

  1. Put file in folder: .minecraft/config/worldedit/schematics/ (or server plugins/WorldEdit/schematics/)
  2. Load into clipboard: //schem load <filename>
  3. Stand where you want it: Navigate to your desired build spot in game.
  4. Paste into world: //paste -a (the -a skips air blocks so you don't overwrite surrounding terrain!)
Option 2 (Survival Friendly)

Litematica (.litematic)

Best for vanilla survival worlds, projection holograms, and material counting with Malilib.

  1. Drop file in: .minecraft/schematics/
  2. Open Litematica Menu: Press M in game and click Load Schematics.
  3. Place Hologram: Select the file, click Load Schematic, and position the ghost projection where you want.
  4. Paste or Build by Hand: In Creative, switch tool mode to Paste Schematic (Ctrl + Alt + Execute). In Survival, use the hologram projection to place each block accurately!
Pro Tips

Placement & Safety Tips

Avoid common glitches when pasting large structures or complex redstone mechanisms.

  • Always backup your world: Create a world save backup before pasting large megabuilds.
  • Redstone ticking: Run /gamerule randomTickSpeed 0 before pasting large redstone machines so pistons don't trigger mid-paste.
  • Undo button: If you placed it in the wrong direction, immediately type //undo.
  • Rotating: Rotate schematics before pasting with //rotate 90, //rotate 180, or //rotate 270.
